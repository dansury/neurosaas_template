# Учётная запись администратора

Здесь хранится вход в админку: создание пароля, подтверждение email шестизначным кодом и восстановление доступа. Откройте `admin/`, заполните форму и введите код из письма. Если письмо не пришло, проверьте спам и отправку почты у хостинга. Файлы этой папки вручную запускать не нужно.

Technical contract: [account and administration](../../specs/admin-layout.md). State is private, locked and preserved during deployments.

Что вы увидите, если загрузить файлы и ничего не программировать

Реальные снимки работающего PHP-шаблона: стартовая страница, оба способа установки и готовая инфраструктура. Чат, CRM и другой прикладной продукт ещё нужно разработать.

Офлайн-сценарий: распаковать полный ZIP → загрузить содержимое на PHP-хостинг → /admin/?install=local → пароль → подтверждение email. GitHub можно подключить позже. Для AI и почты нужен доступ к их сервисам.

Снимки сделаны через Playwright на PHP 8.5. Подтверждение email пройдено с тестовой доставкой. Реальные письма, платные AI-запросы и отправка задач из формы не выполнялись. Пример owner/repo использует тестовый ответ GitHub. Нажмите на любой экран для увеличения; длинные экраны можно прокрутить.

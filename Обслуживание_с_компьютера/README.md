# Обслуживание с компьютера

Эта папка нужна разработчику, который вручную переносит подготовленный модуль между репозиториями. Сайт её не использует; для установки, настроек и обычного обновления ничего отсюда запускать не нужно — используйте админку.

`sync_toolkit.py` копирует файлы модуля и его спецификации из точно указанной версии локального Git-репозитория. Он не подключается к сайту и не переносит секреты или локальные данные. Запускайте на компьютере с Python 3 и Git из папки проекта:

```sh
python3 Обслуживание_с_компьютера/sync_toolkit.py --source /путь/к/репозиторию --revision ПОЛНЫЙ_ХЕШ_КОММИТА
bash tests/run_all.sh
```

После выполнения просмотрите изменения перед коммитом. Указанный репозиторий должен содержать admin/llm_connector и specs/llm_connector.
